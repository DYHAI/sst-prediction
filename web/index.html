南海海温预测擂台

预测南海 7 个海区未来 1 / 3 / 5 天的日均海表温度 —— 和 HYCOM、GFS、CFSv2，以及本站模型同台比分。

你是哪位

填个名字会在这台机器上生成一个私钥（token），以后提交都用它，不需要邮箱。

手动填写

时效 h 天的意思：必须在目标日往前 h 天的 00:00 UTC（北京 08:00）之前提交，过点不能改。 单位 °C，可以留空。

上传整个预报产品（推荐给模型玩家）

直接把你模型的输出丢过来，我们负责解析、按海区聚合、自动评测、自动上榜单。 支持 CSV（海区表或网格场）、NetCDF（.nc）、Parquet。 网格文件需要 lat / lon / sst 三列（或三维数组），时空列名常见写法都认。 时区统一按 UTC 日期；温度写开尔文或摄氏度都可以，自动识别。

命令行 / API 提交方式 
# 首次：登记名字，会打印 token
python3 -m tools.submit_file --name "我的模型" --file pred.csv

# 以后每天自动提交
python3 -m tools.submit_file --token <TOKEN> --file pred.nc

# 接口方式（可接进你的训练脚本）
curl -F name=我的模型 -F token=<TOKEN> -F file=@pred.parquet \
     https://sst.playai.org.cn/api/upload
